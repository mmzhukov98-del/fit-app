# Мой фитнес — личный дневник тренировок и питания

Мобильное веб-приложение (PWA) в стиле iOS: тренировки, питание, вес и замеры, нагрузка, недельные отчёты.
Работает без сервера и регистрации — все данные хранятся только в браузере телефона.

## Установка на iPhone
1. Открой ссылку на приложение в **Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»**.
3. Запусти приложение с иконки → Профиль → Данные → **Восстановить из копии** → выбери файл `profile-setup.json` (его присылают отдельно, в репозитории его нет).
4. Профиль → Напоминания → **Добавить в Календарь** — так придут уведомления о взвешивании, замерах и тренировках.

## Как пользоваться
- **Главная** — кольца дня (питание, активность, вода), план дня, неделя.
- **Тренировки** — A → B → C по кругу; запись подходов, таймер отдыха, отчёт, предложения по весу (только с подтверждением).
- **Питание** — «Съела» в одно касание, замены блюд, свои продукты, вес сырой/готовый, вода, меню, покупки, рецепты, КБЖУ продуктов.
- **Календарь** — месяц/неделя, отметки, карточка дня, планирование тренировок.
- **Профиль** — показатели и графики, нагрузка, недельный отчёт с оценкой, цели и КБЖУ, напоминания, резервная копия, CSV.

## Цикл корректировки с Claude
1. Раз в неделю: Профиль → Еженедельный отчёт → **Скопировать** (или «Файл» и положить в папку `reports/`).
2. Отправить отчёт Claude в чат.
3. Claude разбирает неделю, предлагает изменения и после согласия правит файлы в `js/data/`:
   - `program.js` — тренировки, `exercises.js` — упражнения и видео, `foods.js` — продукты, рецепты, меню;
   - `plan-meta.js` — повышает `PLAN_VERSION` и добавляет запись «что и почему изменилось»;
   - `sw.js` — повышает версию кэша (`CACHE`).
4. После публикации приложение на телефоне обновится при следующем открытии и попросит подтвердить изменения. Записи пользователя не затрагиваются.

## Локальный запуск
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
Затем открыть http://localhost:8080

## Приватность
- Никаких внешних запросов (строгий CSP), аналитики и сторонних шрифтов.
- Личные данные (`personal/`, `reports/`, резервные копии) исключены из репозитория через `.gitignore`.
- Приложение не заменяет врача.
