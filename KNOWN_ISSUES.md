# Известные проблемы и ограничения

| Приоритет | Проблема | Последствие | План |
|---|---|---|---|
| P2 | Данные хранятся только в памяти браузера телефона, без облака | при потере/сбросе телефона без резервной копии данные теряются | еженедельное напоминание о копии уже есть; опционально — шифрованная копия |
| P2 | Резервные копии не зашифрованы | файл со сведениями о здоровье читаем при утечке | шифрование паролем (WebCrypto) |
| P2 | Если вести оба профиля на одном телефоне, рабочие веса упражнений смешиваются | неверные стартовые веса | разделить ключи по профилю (сейчас каждый на своём телефоне — проблемы нет) |
| P2 | В публичном коде остаются обезличенные детали программы (пульс покоя, история бега, адрес магазина цен) | минимальный риск приватности | обобщить формулировки |
| P2 | Нет автотестов в репозитории | регрессии ловятся вручную | `tests.html` с юнит-тестами расчётов |
| P3 | Цена и новый показатель замеров вводятся через системное окно `prompt` | выглядит не по-iOS | заменить на шторку |
| P3 | Размер шрифта не следует настройке «Размер текста» iOS (Dynamic Type) | хуже доступность | перейти на системные текстовые стили |
| P3 | VoiceOver-подписи есть не у всех элементов | хуже доступность | аудит на устройстве |
| — | Нет push-уведомлений | напоминания — через Календарь iPhone (.ics) и внутри приложения | ограничение PWA без сервера |
| — | Нет Apple Health / Apple Watch | данные часов вносятся вручную | возможно только в нативном приложении |
| — | Даты стартов 2027 (Казань, Москва) не объявлены | сезонный план ориентировочный | обновить после открытия регистрации |
| — | Часть цен в списке покупок не проверена по магазину; у молочного шоколада цены нет совсем | бюджет приблизительный, шоколад в сумму не входит | вписать по чекам (цены редактируются в приложении) |
| P3 | Если вести оба профиля на одном телефоне, тренировки и еда общие | путаница при тестах на одном устройстве | у каждого свой телефон — проблемы нет |

## Не готово к App Store
Это PWA. Для App Store нужна нативная оболочка (Swift/SwiftUI или Capacitor), privacy manifest, HealthKit-разрешения, подпись и сборка в Xcode — отдельный проект.
